# Pagus テスト計画

Pagus は決定的な sim、SQLite 永続化、WebSocket 配信を重要経路とする。

- sim: 戦闘・事件・裁判・生活状態機械を単体テストし、乱数は注入して固定する。
- 永続化: world の後方互換、旧 JSON 移行、履歴の順序・保持上限、DB 再オープンを検証する。
- メモリ: 年代記・チャットがDB直読みであること、ターム単位集合が切替時に解放されること、退場住民の関係・信仰がDBへ移ることを検証する。
- 統合: server の主要 WS/HTTP 経路、入力上限、切断時の listener/socket 解放を検証する。
- CI: build / typecheck / test を実行し、メモリ最適化では長時間シミュレーション時の heap と GC の回帰を観測する。

充実の基準は、ゲーム進行の決定性、セーブ後方互換、DB障害・空・上限などの異常系を同じ変更で固定できていることとする。
