# Pagus：住民の行動を自律BTに統一し、LLMを期限付き介入にする比較版

## 実装内容

この版の中心変更は `spec/feature/resident-bt-autonomy.md`。日常・休息・移動目的・事件反応・投票・教育・裁判発言を同期BTで選び、選択したノードを住民詳細に表示する。従来LLMが直接決めていた事件・投票・教育もローカル実装へ置き換える。LLMは人間が神の声チャットへ投稿したときだけ、鎮静・調査・集合の提案を作る。住民は自分のBTで受諾／拒否し、提案は2セグメントで失効する。

`PAGUS_RESIDENT_CONTROL=bt` が既定。`legacy` で従来方式を選べる。BT版は自動shadow sampling・自動蒸留・自動LLM要約を呼ばず、既存の蒸留済み行動規則を使って自律進行する。LLMの応答待ちはゲームループをブロックしない。

前の版を保持して比較するため、ローカルmain起点の別worktreeに前版の3コミットを取り込んだ。このPRは以下の3D街と住民の基盤も含む。前PR #1471 と基盤差分が重複するため、両方を独立機能として重ねて取り込まないこと。

広場だけの舞台を一つの街へ再構築。中央の噴水と7業種の店、郊外の住宅16戸、野営地、隔離された離れ、狩猟林を同一マップに配置する。店舗・住居の入口をサーバーの目的地とし、建物を避ける経路をWebGL2で描画する。裁判も同じ噴水広場で行う。

住民は活動特性に応じて食事・通勤／狩猟・交流・帰宅を行う。住居の有無・喪失・隔離とその事情を保存し、建物から住人と働く人を、住民詳細から一日の時刻表を確認できる。初期の8人以上の街には3人の住居事情を背景設定として加える。店舗は日課の目的地であり売買／診療／狩猟戦闘は追加していない。PictorはC++/Emscripten実装を調査し、描画は既存のWebGL2を使用する。

固定の動物画像では教育が見えず、画面の歩行も実際の行動と一致していなかった。村と裁判の舞台を3Dにし、既存7種の獣人へ教育履歴に対応する8種の混合を追加した。触手、第三の目、ティーポット、ぜんまいに加え、スライム化、4本腕、別種の頭、クトゥルフ風の口元の触手を表現する。

住民の目的選択と移動をサーバー側の優先セレクターに統一。既存LLM提案・蒸留ルールの出力後に教育ゲートを適用し、優先度、割り込み、加害／噂の抑制を履歴とともに表示する。教育の性格差分を値として上書きしていた不整合も修正。

静穏・反復に応じた予兆、殺人／価値観の衝突の事件、段階的な記録と証言、裁判後の余韻を導入。既存の投票・量刑・火種を維持し、同じ事件記録をLLM判断にも渡す。完全な秘密役職型マダミスの通信契約は今回の範囲外。

## 受け入れ条件

- BT版で事件・投票・教育・住民発言を含む住民判断がLLMの直接出力に依存しない。
- LLM介入は許可された3intentのみで、住民の受諾判定と期限を通る。教育ゲートを迂回しない。
- 直近の選択ノードと判断を住民詳細で確認でき、保存済みルールは継続利用する。

- 噴水広場・7店舗・郊外住宅・野営地・離れ・狩猟林を同じ街で表示し、建物から住人と職業を確認できる。
- 日課が昼行性／夜行性／薄明性に従って切り替わり、寝床への帰路と教育割り込みも占有セルを避ける。
- 住居事情と日課を保存・復元し、移住者だけ新規に割り当てる。混合外見を迫害の根拠にしない。

- 通常7種と混合後の姿を判別でき、頭と胴体を別種にできる。
- 教育理由と前後の値、現在の目的、割り込み、抑制された候補を住民詳細で確認できる。
- 画面の歩行はサーバー座標を追い、教育ゲートが副作用適用より前に働く。
- 進行中の事件を上書きせず、予兆・事件・裁判・余韻が連続する。
- TypeScriptのsim/client/server静的確認は成功。PNG比較は本番メッシュ頂点からオフライン生成し、ユーザーへ2回添付した。
- **ユーザー指示によりテスト・サービス起動／再起動・マージ・main更新は実行しない。PR作成後停止する。** ブラウザ接続がなく、実WebGL描画やゲーム一巡は未検証。
