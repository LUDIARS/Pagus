# 村の存在感と観戦者への呼びかけ

2026-09-08 neco 指示。UX は「ライバルピーク的な次世代のAIドリブンゲーム」。
観戦するだけでも住民の生活と関係が見え、人間の間接介入が次の展開へつながる。

## PA-PRESENCE-01 住民の動き

既存のサーバー BT、教育ゲート、通行判定を再利用する。自由時間には散歩と近隣住民への接近を選ぶ。
攻撃的な個体は威圧的な歩調・会話を見せる。睡眠、隔離、勤務と教育による抑制を優先する。
クライアントはサーバーの経路を補間し、歩行の向き・上下動・身体の揺れを描画する。

## PA-PRESENCE-02 目と詳細モデル

ネジつきは既存 clockwork、獣つきは既存 hybrid（別種の頭）の教育形態に対応する。
ネジつきの目から白いハイライトを除き、獣つきは赤い目にする。両方あれば両条件を適用する。
スライム等と合成しても目の指定を保持する。街と住民一覧で同じ形状を使う。
住民用曲面の分割数を増やし、耳の内側・指先・衣服などの細部を追加して大きく描く。

## PA-PRESENCE-03 噴水を中心とする村

Fg の cityplan-roads / semantic-city-plan の道路先行・通行域と敷地分離を参照する。
欧州の広場と街路を着想源に、噴水広場から放射状の主街路、環状の小道、建物への支道を構成する。
道路セルの正本は sim。描画と経路探索が同じ道路を使い、石畳を優先して歩く。
既存住宅 ID と入居データを保ち、広場は平坦、周縁はなだらかな起伏を持たせる。
地面・建物・住民・アイテム・ラベルは同じ高さ関数を使う。

## PA-PRESENCE-04 非公開の呼びかけ

LLM が住民の中から観戦者に話しかける個体と発動スイッチを決める。
人間の発言がなくても神の声チャットへ短い問いかけを投稿する。既存の返答経路で人間が返せる。
対象候補・発動スイッチ・判断理由は World、WireWorld、公開 API、行動ログ、BT履歴へ載せない。
発言者と実際の発言だけを既存 ChatMessage として保存・配信する。未発動の対象は判別できない。
サーバー内の有界状態として扱い、接続者なし・一時停止・裁判中・死亡・隠れた個体では発動しない。
同時推論は1件。間隔と個体別クールダウンを設け、遅延結果は再検証する。停止後の結果は破棄する。
PAGUS_BRAIN=llm で有効。明示的な stub モードではこの LLM 機能は無効で、擬似発言へ置換しない。

## 構成と確認

sim は道路・日課、client は形状・地形・動作表示、server は非公開LLM判断と既存チャット配信を担当する。
Anatomia の where/find で既存 townRoute と各ドメインを照合して再利用する。
単体・統合・動作テストはユーザー指示により実行しない。静的型確認・差分確認・Anatomia解析を実施する。
実表示、経路一巡、LLM発動と公開データ非露出の動作確認は未検証として管理する。
