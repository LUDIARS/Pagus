# 一つの街と住民の生活

## 街の構成

中央の噴水広場を囲んで医者・雑貨屋・大工・服屋・八百屋・飯屋・宿屋を配置する。郊外に16戸、共同の野営地、迫害から逃れた住民の離れ、街道の先の狩猟林を置く。一つのフィールドを共有し、裁判も噴水広場に住民を配置して見せる。

`packages/sim/src/town-map.ts` が配置・入口・占有セルの正本。既存の24×24グリッドを基準に設定サイズへ写像する。`town-navigation.ts` は上下左右BFSで占有セルを回避する。通常日課・教育割り込み・学習された移動バイアスの最終移動は同じ経路探索を通し、1セグメントで最大8セル進む。建物の内部ではなく入口を到達地点とする。小さい独自グリッドでは建物配置が重なるため、街の標準表示は24×24を前提とする。

## 暮らしの保存

`town-residency.ts` の `TownLife` を Villager に任意フィールドとして追加。新規世界・snapshot復元・移住後の最初の日常tickで未割り当て分だけ初期化する。既存の種・教育・性格は保持し、職場と住居は再抽選しない。snapshotバージョンは11を維持する。

職業は7店舗と狩猟へ人数を均等に割り当て、通常は空いた郊外の家へ定住する。住宅不足では野営地を使う。8人以上で初めて街を構成するときは、狩猟担当を除く3人に「家を持たない」「以前の火災で家を失った」「以前の迫害で隔離された」という初期背景を設定する。これは過去のプレイログからの推定ではなく初期設定であり、再読み込みや移住ごとには繰り返さない。種や混合外見を根拠に迫害対象を選ばない。

`changeHousing` は事情を必須とし旧居を保存する。日常行動で6回の嫌がらせを受けた住民は離れへ退避する。隔離中は職場への通勤ではなく内職・道具の手入れを行う。損壊した旧居は瓦礫として表示し、隔離のため留守の家と区別する。自動再建・支援・再入居のプレイヤー操作は今回追加していない。

## 目的と一日

`town-routine.ts` が時計と既存の活動特性から日課を決める。起床後に食事、店舗での仕事または狩猟、噴水広場での交流、帰宅・休息へ進む。夜行性の勤務は日付をまたぐ。薄明性の短い活動帯は勤務を優先する。移動距離が時間内に収まらなければ「移動中」であり、到着済みとは表示しない。睡眠帯も帰宅経路を進めるが、LLM／日常の加害候補は生成しない。

`resident-goals.ts` の教育優先セレクターとハーネスゲートを維持する。帰宅・休息と隔離条件を先に扱い、活動中はケア・調査の割り込み、規律による通勤優先、欲望による収集が日課に影響する。学習された訪問は交流枠で目的地を変える。最終経路を `BehaviorTrace.route` で配信する。

`EnvironmentView.townActivity/townSite` を DailyEngine と LLM の行動プロンプトへ渡す。既存の蒸留されたBehaviorRule評価は維持する。日常の移動判断にLLM呼び出しは追加しない。

## 描画と操作

WebGL2を使用。Pictorの `include/pictor/webgl/webgl_renderer.h` とCMake定義を調査したが、これはC++/Emscriptenの参照レンダラーであり、Pagus向けの公開JS接続はない。この変更はPictor実体を組み込んだものではない。sibling依存・未提供WASMへの無言フォールバックは追加しない。

`town-buildings.ts` が看板・屋根・屋台・煙突・噴水・住居の形状、`town-scenery.ts` が道路と背景、`town-coordinates.ts` が座標変換を担当。`TownLabels` は住人・働く人・住居事情を表示する。建物を選ぶとカメラが寄り、⌂で街全体に戻る。住民詳細は現在の日課と時刻表を表示する。

`StageView` は受信した経路の各点を順に補間する。裁判への出入りは同じ街の中で演出位置とサーバー位置を切り替える。長期間の非表示で64点を超える遅延は最新座標へ再同期し、経路を無限に蓄積しない。背景メッシュの更新時は新規確保成功後に旧バッファを解放し、破棄時はDOM・コールバック・GPU資源を解放する。

## 確認と境界

ユーザー指示により単体・統合・起動テスト、サービス再起動は実施しない。sim/client/serverのTypeScript静的確認とdiffの確認を行う。実WebGLの見た目・操作・セーブ再開・一日進行は未検証。

店舗は職場と日課の目的地であり、商品売買・診療処理・宿泊契約・狩猟戦闘を備える経営シミュレーションではない。住民経済は既存の日末決済を継続する。屋内・住民同士の衝突回避・経路混雑・季節別営業も今回の範囲に含まない。
