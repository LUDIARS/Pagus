# 住民一覧の教育回数・モデル表示

## 表示

- 生活ステータス一覧の各行に `教育:N回` を表示する。値は詳細画面と同じ `Villager.reformCount`。保持期間のある教育履歴配列の長さを回数に使わない。
- 行の左側に現在の住民モデルを80pxの静止プレビューで表示する。画像を含む行のクリック・Enter・Space操作で既存の住民詳細を開く。
- `residentParts` と `triangulate` を街の3D描画と共有し、種族・色・別種頭部・スライム・触手など教育後の形状を反映する。Canvas 2Dで同じメッシュを正投影した画像であり、別の汎用動物アイコンではない。
- 自動で全パーツを収める画角と代替テキストを用意する。2D描画が利用できない場合はモデルが表示できない旨を示す。

## 負荷・寿命

- 見える行をIntersectionObserverで検出してからメッシュを画像化する。住民ごとのWebGLコンテキストやアニメーションループは作らない。
- 形状をキーに最大128枚をキャッシュし、教育で形状が変わると画像を作り直す。未変更のモデルは画像を再利用する。
- 一覧の更新時は旧行の監視と参照を破棄する。pagehide時も監視とキャッシュを解放する。

## 確認

- clientの型チェックと差分検査を実施。
- 単体・統合・起動テスト、サービス反映は未実施。次回の許可済み画面確認では通常住民、混合住民、教育0回と複数回、一覧スクロール、詳細を開く操作を確認する。
