# 住民を観察する画角・裁判会話・隔離方針

2026-09-09 neco指示。「画面引きすぎ」「モデルが適当」「住民の隔離属性を解除。隔離判定を見直す」「裁判は以前のように演出とともにそれぞれの住民が言い合う感じ」。

- 初期カメラはzoom 4.5。寄りは8まで操作可能。
- 顔の面構成・羽毛と衣服の襟、袖口、前立て、ボタン、靴を描き、熊と兎と蛇のシルエットを区別する。教育による変異と目の指定を保持する。
- 裁判のサーバー発言は話者を失わず順番に表示する。告発・被告側を色分けし、発言中の住民の名札・向き・身振りを強調、カメラを追従させる。同一発言を受信し直しても再生し直さない。減速モーション設定では会話枠アニメーションとカメラ補間を省略。
- 初期住民への隔離割当を廃止。旧住民の隔離はpolicy version 2への移行時に一回だけ解除する。職業・帰還先の住宅情報・関係を保持する。
- 再隔離条件は1日以内の異なる6時間帯の嫌がらせ被害、恐怖0.8以上、解除後3日の猶予経過をすべて満たすこと。種族や教育による見た目は条件にしない。
- 嫌がらせは被害者の恐怖を1回あたり0.14上げる (`recordTownHarassment`)。ふるまいの法則は行動した本人にしか感情差分を与えないため、この加算が無いと被害者の恐怖は0のままで恐怖条件が永久に成立しない。6回目でちょうど0.8へ届き、回数条件と恐怖条件が一致する。
- 隔離後3日平穏で復帰する。稼働中の解除はこの変更が反映され、次の日常行動処理で移行が走った後となる。
