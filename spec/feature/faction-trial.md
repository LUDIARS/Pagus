# 噴水広場の勢力裁判

## 確定要件

ユーザー指定: 開廷時に画面端からトランジションし、噴水広場に双方最大10人を描画する。住民BTが議論から勝敗を決め、投票で負け側全員への教育または廃棄処分を決める。

## 勢力と議論

- 開廷時に公開・生存住民から告発側と被告側を固定する。被告側代表は告発対象（擦り付け先があればその住民）、告発側代表は事件関係者または別の住民。関係値と安定ID順で各最大10人に割り当て、重複させない。
- 2人未満で双方を作れない場合や導入前の保存裁判は従来方式を維持する。存在しない対立者を生成しない。
- `faction-trial.ts` が一歩につき一人の発言をBTで決定する。教育による自制、目撃証言、矛盾への反論、攻撃的な罵倒、生活を守る反発の優先順位。各選択は既存btHistoryに残る。
- 各勢力2巡の説得点を人数で正規化して比較する。真犯人の隠された正解や人間の勝敗票は参照しない。同点なら立証責任のある告発側が敗北する。結果と理由はTrialStateに保持する。

## 量刑・制裁

- 勝敗確定後、既存の住民・ユーザーによるkill/spare投票を敗北勢力全員の量刑に使う。勝敗は量刑票で逆転しない。既存のwholesome設定では教育のみという制約を維持する。
- 敗北側の名簿と対象全員を量刑パネルに明示する。勝利側および勢力外の住民へ制裁しない。
- 教育は各対象のBTから個別に指示を作り、既存reform経路で人格・外見・教育回数へ反映する。廃棄処分は全対象をalive=falseへ変更する。
- 制裁指示列と適用済みIDをTrialState内に保存し、途中復帰で対象を入れ替えたり二重教育したりしない。既存の日末評価・後日談も継続する。

## 描画

- `court-frame.ts` は噴水前の左右に各10席を用意し、法廷用areaFrameに演出座標を入れる。日常World座標を上書きしない。法廷終了後は元の生活座標の配信に戻る。
- クライアントは端から覆うワイプの中間でplazaを購読する。旧エリアの再生を遷移中に受理しない。終了時は直前の閲覧区画へ戻す。裁判中の通常エリア選択は停止する。
- 告発側は赤、被告側は青のラベル。現在話している住民を小さく揺らし、BTが選んだ言い争いを表示する。単一被告向けの別生成ナレーションは混ぜない。
- reduced-motion時はワイプを省略する。画面破棄・連続した遷移ではアニメーションを取り消す。施設10・住民30の予算内（法廷参加者は最大20）。

## 検証

- client/server型チェックでsimを含む契約を確認。単体・統合・起動テスト、サービス反映は未実施。
- 許可後に確認: 通常開廷・固定被告裁判、20人の左右配置、議論終了と同点、教育と廃棄の全員適用、勝利側無変更、制裁前後の保存復帰、裁判中接続、連続遷移、元エリアへの復帰。
