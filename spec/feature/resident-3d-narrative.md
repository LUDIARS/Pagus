# 教育で混ざる3D住民と物語の進行

## 目的と設計

住民の教育を、説明文だけでなく形状・次の目的・行動の抑制として観察できるようにする。猫、兎、梟、熊、栗鼠、鼯鼠、蛇の既存種を維持する。Figmentum `web/avatar-demo-field.js` と `avatar-demo-polygon-renderer.js` の係数パーツ・ポリゴン描画の方式を参考に、Pagusの独立したTypeScript実装で低ポリゴンの楕円体と箱を構成する。Fgのネイティブ生成器・SDF融合そのものを組み込んだものではない。sibling依存や描画ライブラリの追加はない。

3Dメッシュ係数、三角形化、GPU資源管理、舞台背景、物語表示、ステージ制御は責務ごとに分離する。単一WebGL2コンテキストを所有し、モデル変更時は新しいメッシュを確保してから旧GPU資源を解放する。WebGL2非対応は理由を表示する。

## 教育

| 方向 | 混合パーツ | 行動への影響 |
|---|---|---|
| 共感 | 触手 → スライム化 | 不安・怒りの強い住民へのケア割り込み、加害候補を最終ゲートで抑制 |
| 規律 | ぜんまい → 4本腕 | 日課を収集より優先、加害と噂伝播を抑制 |
| 探究 | 第三の目 → 深淵の触手 | 穢れた場所の調査が日課へ割り込む |
| 欲望 | ティーポット → 別種の頭 | 落ちている品への移動を優先 |

教育方向はLLMが閉じたenumで指定可能。未指定なら性格の実際の変化量から推定する。性格は差分加算後0..1に制限する。外見部品は蓄積し、理由・前後の外見・前後の性格は直近12件を保存する。古いsnapshotに記録がないとき、過去の教育理由を捏造しない。

同じ方向で再教育されると未獲得の第2形態へ進む。全8系統を別々に組合せ可能。頭の別種は本人のidから決定し、元の種は胴体とシミュレーションに残す。スライムは形状・色・水たまり状の裾・光沢で表し、現時点では半透明屈折ではない。深淵の触手は口元から垂れる5本の曲線と吸盤、背中の膜を持つ。

## 行動と蒸留

既存のBehaviorRule DSL（base/haiku/distill/card）とshadow samplingを継続する。LLMから提案・蒸留されたルールはDailyEngineで自律評価される。日常tickではLLMを呼ばない。起きている全住民の行動を評価し、EventDirectorの代表だけに歩行を限定しない。

最終境界のreactive priority selectorは、帰宅・休息および隔離生活を先に判定し、活動中はケア100→調査90→規律の日課80→収集70→通常日課50の順で選ぶ。日課は時計に従い切り替わり、割り込み条件が消えれば現在の日課へ戻る。街の配置・通勤・建物回避は [街と生活ルーティン](town-life.md) に従う。

ルール・関係行動の候補を作った後、教育の最終ゲートを適用し、それから位置・感情・関係・金銭・情報を更新する。共感／規律が攻撃性を上回る場合に加害を抑え、友好的な関係変化と正の金銭効果は残す。教育の割り込みでは候補全体をケア／調査に置き換える。抑制は任意文字列の検閲ではなく、構造化された加害・事件化・噂の行動を対象とする。住民詳細は目的・候補・実行・抑制理由を表示する。画面はサーバー経路を補間し、乱歩を作らない。

## 物語

フレーム数ではなくゲーム内セグメントで静穏を数える。1日程度の静穏、または通常事件が3回続いた後に予兆を出し、予兆の次セグメント以降に物語事件を挿入する。裁判後は2タームの余韻を設け、日常由来の再事件化を抑える。プレイヤーの明示的扇動・制裁や月次事件は既存の仕組みを尊重する。事件／裁判の重複、同日の再裁判は追加しない。

「灯の消えた晩餐会」（村外の旅商人が被害者）と「教育された証人の裁判」を交互に構成する。wholesomeでは殺人を贈り物の紛失事件に置き換える。既存住民・過去の教育理由を筋書きに織り込み、開廷で提示する記録と量刑段階で開示する証言を分ける。記録を朗読しただけの住民に告発票を加算しない。LLMの事件進行・投票・教育にも同じ事件記録を渡す。判決の既存plot threadが次の物語の材料として残る。

## 確認状態

通常／混合7種類の比較PNGを同じメッシュ頂点からオフライン出力した。これは実ゲームのスクリーンショットではない。ユーザーの方針に従い単体・統合・起動テストは行わない。ブラウザ接続が利用不可のため、実WebGL表示・操作・長時間のGPU資源推移は未確認。型の静的確認のみを行う。
