# 初期読み込み画面

## 表示と準備完了

- index.htmlに初期表示を置き、モジュール取得前から「街を読み込んでいます」を表示する。
- 接続、街情報受信、建物・住民描画の3段階を示す。架空の進捗パーセントは表示しない。
- StageViewが全体snapshotと受理済みareaFrameから最初のフレームを描いた時点で閉じる。住民0人の区画でも完了する。裁判トランジション中の未描画状態では完了させない。
- アプリ本体は初期状態でinert/aria-busy。読み込み解除時に操作できるようにし、読み込み画面内にキーボードフォーカスがあった場合はメイン操作へ戻す。

## 待機・失敗

- 20秒を超える待機では説明と「先に画面を開く」を表示する。接続失敗時も既存の自動再接続を止めずに状態を案内する。
- 再読み込みリンクは最初から利用でき、モジュール読み込み失敗でも操作可能。JavaScript無効時には明示メッセージを出す。
- 3D初期化失敗またはmain初期化例外は待機表示のまま隠さず、再読み込みまたは既存画面を開く選択を示す。
- 初期読み込み終了後の通信切断は既存ステータスバーに任せ、全画面を再度覆わない。

## 寿命・確認

- 終了時またはpagehideで待機タイマーとイベントを解放する。スピナーはreduced-motion指定時に回転しない。
- client型チェックと差分確認を行う。動作・起動テストやサービス反映は未実施。
- 次回の許可済み画面確認では通常接続、空エリア、裁判途中の接続、接続失敗、描画不可、キーボード操作を確認する。
