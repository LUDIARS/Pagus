# Pagus 運用方針

- data/runtime/pagus.sqlite をゲームデータの権威とし、WALを含めてバックアップする。
- 起動時DDLは冪等に適用する。書き込み失敗はサーバーログへ出し、成功扱いにしない。
- SQLite page cache は約4 MiB、mmapは無効、tempはファイルへ置き、DB由来の常駐メモリを限定する。
- process RSS / heapUsed / GC停止時間 / worldの住民数・関係数 / DBファイルとWAL容量を長時間監視する。
- 年代記10,000、チャット5,000、行動10,000、セッション50,000、シーズン1,000件を保持上限とする。
- 正常終了では最新worldを保存してDB接続を閉じる。異常終了後はWAL復旧と直近スナップショットのロードを確認する。
- 退場住民の関係・信仰はDBへ退避し、復活時に生存住民とのデータだけを作業集合へ戻す。
