# UX-PA-PRODUCT

## 体験

「ライバルピーク的な次世代のAIドリブンゲーム」（2026-09-08 neco）。
人格を持った住民の暮らしを観戦し、関係や事件の続きを気にかけ、人間の間接介入で展開に関わる。

## コアドメイン案

| ドメイン | 体験への貢献 |
|---|---|
| AIによる意思決定・創発 | 文脈・記憶を解釈し、行動・発言・事件を生む。LLM接続とコスト管理は支援基盤 |
| 住民の生活・関係 | 歩行、仕事、交流、対立と個体の連続性を見せる |
| 裁判と教育 | 事件を裁き、教育の結果が人格・外見・行動に残る |
| 人間の間接介入 | 呼びかけへの返答、応援、扇動、投票で住民に関わる |

## 評価する体験

- 住民を見て、その個体の目的や関係がわかり、次の行動を見たくなる。
- 教育前後の外見と行動の違いがわかり、裁判の結果に意味を感じる。
- 住民から自発的に話しかけられ、返答や介入が可能だとわかる。
- 仕組みの内部パラメータを読むことを遊びの前提にしない。

これらは目標であり、UX達成を検証済みとは扱わない。今回の詳細は feature/village-presence.md。
仕様管理は Praeforma の Pagus プロジェクトに集約し、本リポジトリはレビュー可能な実装対応資料を保持する。
