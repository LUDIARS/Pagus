# Pagus 進捗資料 (2026-06-25)

## 1. これは何か

村の住民（**どうぶつ**）が LLM 駆動で自律行動し、**事件 → 投票裁判 → 教育(改変) or 追放**を
繰り返して村が変容する創発シミュレーション。研究/ゼミ用プロトタイプで「AI ループの反復速度」を最優先。
正本企画は Notion「AI村を作ろう」。

## 3. 確定した設計

### 時間モデル（永続24h稼働・実カレンダー連動）
```
月 (=実1日=24h, 実カレンダー連動) → 四季・日本の祝日・大きな転換
 └─ 日 = 1ターム = 起承転結1回 = 実 24h÷その月の日数 ≈ 46分
      └─ 12 セグメント (≈3.8分) = イベント/変化の粒度・睡眠帯
```
実時間長はカレンダー導出（自由 config ではない）。sim は壁時計を持たず、server がペースを所有。

### どうぶつ（ペルソナエンジン）
- 三分: **環境=プログラム / 感情=AI / 情報=蓄積**
- 種(species)と活動特性(diurnal/nocturnal/crepuscular/always)で睡眠帯が決まる
- 「改変」で persona/appearance/emotion を書き換え。出生/流入で増え、追放/死刑で減る

### 二層6軸ベクトル
- **村人の性格 = 気質6軸**: 優しさ/攻撃性/社交性/好奇心/規律/野心
- **村の評判 = 徳目6軸**: 善良/悪辣/秩序/活気/知性/信仰（レーダー表示）
- 1:1 対応（優しさ→善良 / 攻撃性→悪辣 / 社交性→活気 / 好奇心→知性 / 規律→秩序 / 野心→信仰）
- グループ = 村人の性格 dominant 軸でまとめた投票 bloc

### ゲームループ（メタ）
1. **起**: 各グループ代表がイベント（嫌がらせ/良い行動/雑談、各最低2回/日＋ランダム）。嫌がらせはピュアブリード優先
2. **承**: 嫌がらせ → 事件（GANs 的に加害者↔被害者を別コンテキスト進行）
3. **転**: 投票裁判 — ①「最も愚かな行動」→被告選出 ②「殺す/活かす」→判決。グループ bloc ＋接続ユーザ投票
4. **結**: 殺す→追放 / 活かす→強制教育（改変）
5. **日末**: 世界側LLMが裁判結果を評価 → 村の徳目レーダー＋個体ベクトル更新 → 村ベクトルに偏った個体が出生

### LLM（マルチモデル分散 = Discutere 方式）
- 単一でなく複数モデルに分散。どうぶつ↔backend を準固定割当
- Claude = `claude -p --output-format json`、**GPT-5.5 = `codex --model gpt-5.5`**（provider 'codex'）
- LUDIARS「API 不使用」規約と CLI で両立。重い局面（裁判/教育/世界評価）は strong tier へ
