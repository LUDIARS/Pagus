# Pagus UX 資料

> 2026-07-02 作成。Anatomia / Thaleia と共有する UX 正本。機能の網羅は [`docs/domain-and-features.md`](./domain-and-features.md)、設計正本は [`spec/SPEC.md`](../spec/SPEC.md)。

## 1. UX コンセプト (一行)

**「Twitch 上でやるポケモンみたいに、みんなで村を賑やかにしたり荒らしたりして盛り上がろう」**

Twitch Plays Pokémon が「1 つのゲーム画面を数万人のチャット入力で操作するカオスの祭り」だったように、
Pagus は **1 つの永続稼働する AI 村**を全員で観戦し、扇動・制裁・応援・裁判参加・しきたり作りで
突っつき合う。操作の主役は個人ではなく**群衆**であり、面白さの主役はプレイヤーではなく
**村人 (AI) が勝手に起こすドラマ**である。

## 2. ターゲットユーザー

**Cult of the Lamb が好きな人。**

Cult of the Lamb のどこが刺さっている人か → Pagus では何がそれに応えるか:

| Cult of the Lamb の魅力 | Pagus での対応物 |
|---|---|
| かわいい動物 × 残酷 (処刑・生贄) のギャップ | Kenney 動物スプライトの村人が糾弾され、断末魔を上げて処刑される |
| 信者 (どうぶつ) を教化し、信仰をコントロールする | 裁判 →「教育」で村人の性格・姿かたちを強制改変。徳目 6 軸に「信仰」 |
| 教団の掟 (Doctrine) を自分で選んで共同体を歪める | **しきたり改定**: プレイヤーがカルマで村のルールを書き、それが次の事件の火種になる |
| 儀式・弔い・墓 | **弔い**: 推しが死ぬと村に追悼の掟が残り続ける。📜 村の歴史 (年代記) |
| 箱庭を神視点で眺め、住人の営み (結婚・不満・裏切り) を愛でる | 結婚 💍・出産 👶・貧富・非行・クズ化・狂人 😈 が自律的に起きる |
| 崇拝される快感 | 推し指名・応援・観客の祈り。村長選挙の世論を間接的に動かす |

差分も明示する: Cult of the Lamb は**一人でカルトを経営する**ゲームだが、Pagus は
**大勢で 1 つの村を取り合う**観戦体験。教祖の座は 1 つではなく、「善導」と「扇動」の
二大陣営が村の魂を綱引きする。

### ペルソナ例

- **ミナ (22)**: Cult of the Lamb と Rimworld のストーリー生成が好き。配信で「みんなで介入できる村」があれば覗きに来る。推しを作って弔いまで見届けたい派。
- **ケイ (27)**: Twitch Plays / 東方 Project 二次創作文化に馴染み。混沌を起こす側。カルマを貯めて偽予言や天災カードで村をざわつかせ、結果の祭りを楽しむ。

## 3. プレイヤーファンタジー

> **あなたは村の外にいる、気まぐれな神々のひとり。**

- 村人はあなたの存在を直接は知らない。あなたの介入は「噂」「天災」「祈り」「掟」として村に現れる。
- 神は一人ではない。祝福する神 (善導) と災いをもたらす神 (扇動) が同じ村を取り合う。
- 神にも家計簿がある: **カルマ**は時間で貯まり、介入で減る。善い神ほど残酷な制裁は高くつく (善性システム)。

## 4. 体験の 5 本柱

### ① 観る — 村は放っておいても面白い

- 24h 永続稼働。実 1 時間 = ゲーム内 1 か月で、**月に 1 度は必ず事件**が起きる (LLM が月初に発生日を仕込み、前日に筋書きと「事件用キャラ」を生成)。
- 日常は BehaviorRule の創発 (貧困→非行、富裕→クズ化、薬物、結婚、選挙) が回り続け、見るたび村が変わっている。
- 📜 村の歴史で「自分がいなかった間のドラマ」を追想できる。

### ② いじる — 荒らしは正規の遊び方

- **扇動**: 「○○がお前の悪口を言っていたぞ」と偽の噂を 1 体に吹き込み、事件を誘発する。
- **制裁**: 気に入らない住民を当日つるし上げ裁判へ。ただし善人プレイヤーほど高額。
- **カード**: 天災 / 神隠し / 入替 / 覚醒 / 偽予言。**アイテム**: 💎 で成金を作り 💊 で狂わせる。
- 沈静化コマンドは**存在しない** (v1.0 で廃止)。村は放っておくと平穏に戻るので、プレイヤーの仕事は波風を立てる側に寄せてある。荒らしと祭りが同義になる設計。

### ③ 推す — 愛着と喪失

- 1 体を**推し指名**: 生存中はカルマ加速、死ねば大損 + 村に追悼の掟 (弔い) が残る。
- 応援で気質を後押し、推し保険でリスクヘッジ、闇市で復活も (課金モック導線)。
- 推しの死は終わりではなく**次の事件の火種**として村に刻まれる — 喪失をコンテンツ化する。

### ④ 裁く — 裁判は闘技場

- 裁判では、まず「誰を裁くか」、次に判決 (死刑 / 教育) を選ぶ。
- プレイヤーの発言に住民が同調/反論し、裁判の場が一巡してから判決へ進む。
- 事件発生日の**予測アワード**、月間 MVP 投票。
- 観戦の緊張が最大化する「転」フェーズに、視聴者参加の山場を全部重ねる。

### ⑤ 競う / 組む — 群衆を構造化する

- **二大陣営** (善導 vs 扇動) の徳目綱引きスコアボード + シーズン制。
- **称号** (破壊神 / 聖人 / 立法者 / 陪審員 …) は行動の最多保持者に動的付与。
- **共闘レイド** (凶悪な連続犯をプレイヤー総出で裁く) と**観客の祈り** (同時多発で全員バフ)。
- Twitch チャットの混沌をそのまま持ち込むのではなく、**投票の 1 人 1 席合算・カルマ経済・陣営**で「秩序ある混沌」に整形する。

## 5. セッション設計 (時間の UX)

| 実時間 | ゲーム内 | 体験 |
|---|---|---|
| ≈4 分 | 1 セグメント | 吹き出し・雑談・小さな変化。眺めているだけで動く |
| ≈46 分 | 1 日 (1 ターム) | 起承転結 1 巡。日末に結婚/出産/経済決済 |
| 1 時間強 | — | **概ね 1 事件** = 1 回の祭り (承→裁判→教育) |
| 24 時間 | 1 か月 | 季節・祝日・月初の事件仕込み・シーズン進行 |

- **アポイントメント型**: 裁判が開くと**離席中の端末へ WebPush**。「村が燃えてるぞ」で呼び戻し、通知クリック → 即投票。
- 短時間接続でも成立: カルマは離席中も自動で貯まる → 帰ってきた時が一番介入できる。
- 長時間不在でも成立: 📜 歴史 + ハイライトで追想 → 弔い・しきたりの痕跡から「自分ごと」を回収。

## 6. コアループ (感情曲線)

```
[平穏] 村を眺める・カルマが貯まる・推しの日常を愛でる
   │ 退屈しはじめた頃に…
[不穏] 噂・貧困・薬物・偽予言 — 自分または他の神が火種を撒く
   │ 月1の事件 or 扇動が着火
[祭り] 事件発生! 当事者が LLM で応答、二次被害、和解するか?
   │ push 通知で神々が集結
[審判] 裁判劇場: 糾弾の応酬 → 誰を裁くか → 死刑/教育に投票
   │ 断末魔 or 安堵
[余韻] 改変された推しの変わり果てた姿 / 弔いの掟 / 称号変動
   └──→ 村は少し歪んだまま [平穏] へ戻る (歪みは蓄積する)
```

狙う感情: **「かわいそう、でも見たい」**。Cult of the Lamb の処刑演出と同じく、
残酷さは常にかわいさ・ユーモア (絵文字語彙 ⚡😈💍👶🕊💎💊🕯、とげとげ吹き出し、断末魔) で包む。

## 7. 画面と操作 (現行実装)

- **3 カラム観戦画面** (モバイルは左右ドロワー): 左 = 被告/当事者ステータス、中央 = PixiJS ステージ (村シーン ⇄ 裁判劇場) + 実況ログ、右 = 徳目レーダー・投票・経済・政治パネル。
- **裁判中は裁判パネルで「誰を裁くか」→「死刑/教育」を選ぶ** — 介入メニューとは分離し、裁判参加として扱う。
- 行動ドック + メニューオーバーレイに介入手段 (扇動/制裁/応援/カード/アイテム/しきたり) を集約。
- 神の介入は村に演出として現れる: プレイヤー由来の吹き出しは色が変わり、狂人の扇動は 😈 で暴かれる。

## 8. トーン & マナー

- **かわいい × 残酷 × 儀式的**。Cult of the Lamb の文法に倣い、深刻な題材 (処刑・追放・貧困) をポップな動物と定型儀式 (糾弾の整列、断末魔、弔いの掟) に落とす。
- 文字は少なく、絵文字とアイコンで語る (📜 歴史 / ⚡ 事件 / 😈 狂人 / 💍 結婚 / 🕯 弔い)。
- 実在の攻撃性を持ち込ませない: 荒らしの対象は常に **AI 村人**であり、プレイヤー間の直接攻撃手段 (送金・晒し) は設けない (送金・銀行は廃止済)。

## 9. UX 上の設計判断 (なぜこうなっているか)

| 判断 | 理由 |
|---|---|
| 沈静化の廃止 | 村は自然に平穏へ収束する。プレイヤー操作を「波風」に一本化して群衆の役割を明確化 |
| 判決を死刑/教育の 2 択に | 群衆投票は選択肢が少ないほど盛り上がる (TPP の民主主義/無政府 2 モードと同型) |
| カルマの自動蓄積 | 「見てるだけ」の視聴者を排除しない。離席が次の介入の資源になる |
| 善性で制裁コスト増 | 「善い神ほど残酷が高くつく」ロールプレイの一貫性 + 制裁スパム抑止 |
| 弔い = しきたり化 | 喪失を消費で終わらせず村の物語資産に変換。リテンションの物語的フック |
| 事件は月 1 保証 + 扇動で追加 | 無課金観戦でも祭りが必ず来る。熱量が高い日は群衆が自分で祭りを増やせる |
| push 通知投票 | 祭り (裁判) の瞬間視聴者数こそが体験の質。TPP の「その場にいた」感の再現 |

## 10. 未検証の UX 仮説 (観戦して調整)

数値バランス (和解率・二次被害率・カルマレート・裁判参加の重み・狂人の重み等) はすべて
暗号化 config で運用調整前提 (SPEC §11)。UX として検証したい仮説:

1. **同時介入の混雑感**: 神が 10 人を超えたとき、扇動が重なって村が壊れすぎないか (戒厳令・クールダウンで足りるか)。
2. **推しの死の感情収支**: 弔いの掟だけで喪失感が回収できるか、闇市復活が「死の軽さ」を招かないか。
3. **陣営の固定化**: 善導/扇動の人数が偏ったときにシーソーが戻る仕掛け (シーズンリセットで十分か)。
4. **通知の頻度体感**: 実 1 時間 1 事件 + 制裁由来の裁判で、push がうるさすぎないか。
